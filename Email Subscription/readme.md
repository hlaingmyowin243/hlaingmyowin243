# 📊 Excel Data Ingestion System (Input Box to Excel)

အသုံးပြုသူများမှ Input Box တွင် အချက်အလက်များ ထည့်သွင်းလိုက်ရုံဖြင့် နောက်ကွယ်ရှိ Excel Sheet (`.xlsx` file) ထဲသို့ ဒေတာများ စနစ်တကျ အလိုအလျောက် သွားရောက်သိမ်းဆည်းပေးသည့် Web Application တစ်ခု ဖြစ်ပါသည်။

---

## 🚀 Features (ပါဝင်သော လုပ်ဆောင်ချက်များ)
* **Live Ingestion:** Form Input များမှတစ်ဆင့် ဒေတာများကို ရိုက်ထည့်ပြီး Submit လုပ်သည်နှင့် Excel ဖိုင်ထဲသို့ Real-time ရောက်ရှိခြင်း။
* **Auto-Formatting:** Excel sheet ထဲတွင် Row အလိုက် ဒေတာများကို သပ်ရပ်စွာ စီတန်းပေးခြင်း။
* **Validation:** မမှန်ကန်သော ဒေတာများနှင့် လွတ်နေသော Input Box များကို စစ်ဆေးတားဆီးပေးခြင်း။

---

## 🛠️ Technologies Used (အသုံးပြုထားသော နည်းပညာများ)
* **Frontend:** HTML5, Tailwind CSS, JavaScript 
* **Excel Integration:** `xlsx` (SheetJS)
