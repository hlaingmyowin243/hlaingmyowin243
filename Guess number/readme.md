# 🎲 Guess My Number Game

JavaScript standard logic များဖြင့် ဖန်တီးထားသည့် ပျော်ရွှင်စရာ ကိန်းဂဏန်းခန့်မှန်းရသော Web Game တစ်ခု ဖြစ်ပါသည်။ ကွန်ပျူတာမှ လျှို့ဝှက်စွာ မှတ်ထားသော (၁ မှ ၂၀ အတွင်း) ဂဏန်းကို အနည်းဆုံးအကြိမ်ရေဖြင့် မှန်ကန်အောင် ခန့်မှန်းကစားရမည် ဖြစ်သည်။

---

## 🚀 Game Features & Logics (ဂိမ်း၏ လုပ်ဆောင်ချက်များနှင့် Logic များ)
* **Secret Number Generation:** ပွဲစဉ်တိုင်းတွင် ၁ မှ ၂၀ အတွင်း လျှို့ဝှက်ဂဏန်းတစ်ခုကို အလိုအလျောက် ကျပန်း (Random) ထုတ်ပေးခြင်း။
* **Hot & Cold Hints:** အသုံးပြုသူ ခန့်မှန်းလိုက်သည့် ဂဏန်းသည် လျှို့ဝှက်ဂဏန်းထက် ကြီးနေပါက "📈 Too High!"၊ ငယ်နေပါက "📉 Too Low!" ဟု အရိပ်အမြွက် ပြသပေးခြင်း။
* **Score & Highscore System:** * ကစားသမားတွင် အမှတ် (Score) ၂၀ ဖြင့် စတင်မည်ဖြစ်ပြီး မှားယွင်းသည့် အကြိမ်တိုင်းတွင် ၁ မှတ်စီ လျော့နည်းသွားမည်။
  * အကယ်၍ ဂဏန်းမှန်သွားပါက လက်ရှိရရှိသည့် အမှတ်သည် ယခင်စံချိန်ဟောင်းထက် များနေလျှင် **Highscore (စံချိန်သစ်)** အဖြစ် အလိုအလျောက် ပြောင်းလဲသိမ်းဆည်းပေးခြင်း။
* **Play Again (Reset Logic):** "Again!" ခလုတ်ကို နှိပ်လိုက်ပါက လက်ရှိရမှတ် (Score)၊ နောက်ခံအရောင်နှင့် လျှို့ဝှက်ဂဏန်းတို့ကို မူလအခြေအနေသို့ ပြန်လည်စတင် (Reset) ပေးသော်လည်း Highscore ကိုမူ ဆက်လက်သိမ်းဆည်းထားပေးခြင်း။

---

## 🛠️ Technologies Used (အသုံးပြုထားသော နည်းပညာများ)
* **Frontend:** HTML5, CSS3 / Tailwind CSS
* **Core Logic:** JavaScript (DOM Manipulation, Math Functions)

---

## 💻 How to Play (ကစားနည်း)

ဒီ Project ကို မိမိစက်ထဲတွင် ဒေါင်းလုဒ်ဆွဲပြီး `index.html` ဖိုင်ကို Browser တွင် (သို့မဟုတ် Open with Live Server ဖြင့်) တိုက်ရိုက်ဖွင့်လှစ်၍ ကစားနိုင်ပါသည်။

1. Input Box တွင် ၁ မှ ၂၀ အတွင်း ဂဏန်းတစ်ခုခု ရိုက်ထည့်ပါ။
2. "Check!" ခလုတ်ကို နှိပ်၍ ခန့်မှန်းချက်ကို စစ်ဆေးပါ။
3. Hint စာသားများကို ကြည့်ပြီး ဂဏန်းကွက်တိမှန်အောင် ထပ်မံခန့်မှန်းပါ။
4. ဂိမ်းကို ပြန်စချင်ပါက "Again!" ခလုတ်ကို နှိပ်ပါ။
