# 📦 Deli Dashboard | Management System

ပို့ဆောင်ရေးလုပ်ငန်း (Delivery Services) များနှင့် ပါဆယ်လုပ်ငန်းများအတွက် အမှာစာများ၊ ပို့ဆောင်သူ (Riders) များနှင့် ငွေစာရင်းများကို တစ်နေရာတည်းတွင် စနစ်တကျ စီမံခန့်ခွဲနိုင်ရန် တည်ဆောက်ထားသည့် ခေတ်မှီ Admin Dashboard Application တစ်ခု ဖြစ်ပါသည်။

---

## 🚀 Features (ပါဝင်သော လုပ်ဆောင်ချက်များ)
* **Real-time Analytics Analytics:** စုစုပေါင်း အမှာစာ (Total Orders)၊ ပို့ဆောင်ဆဲ (In Progress)၊ ပို့ဆောင်ပြီး (Delivered) နှင့် စုစုပေါင်း ရရှိငွေ (Total Revenue) တို့ကို Summary Cards များဖြင့် ရှင်းလင်းစွာ မြင်တွေ့နိုင်ခြင်း။
* **Order Management Table:** Delivery Order များ၏ အခြေအနေ (Status - Pending, Shipped, Delivered) ကို သတ်မှတ်ပေးနိုင်ပြီး ရှာဖွေရလွယ်ကူအောင် Filter & Search စနစ် ထည့်သွင်းထားခြင်း။
* **Rider Tracking & Assignment:** မည်သည့် Rider က မည်သည့် ပါဆယ်ကို ပို့ဆောင်နေသည်ကို စနစ်တကျ စာရင်းသွင်း စောင့်ကြည့်နိုင်ခြင်း။
* **Interactive UI & Charts:** လုပ်ငန်းတိုးတက်မှု ဒေတာများကို Dynamic နည်းလမ်းဖြင့် ကြည့်ရှုနိုင်ရန် စွဲမက်ဖွယ်ကောင်းသော Charts များနှင့် Grid Layout များ အသုံးပြုထားခြင်း။

---

## 🛠️ Technologies Used (အသုံးပြုထားသော နည်းပညာများ)
* **Frontend:** React, Tailwind CSS / HTML5, CSS3
* **State Management & UI Components:** JavaScript (ES6+), Icons 
* **Database & Backend:** *(မိမိ သုံးထားလျှင် Node.js, Express, Prisma, MySQL စသည်ဖြင့် ဖြည့်စွက်နိုင်ပါသည်)*
