# 🔊 Text-to-Voice Converter (Web Application)

အသုံးပြုသူများမှ Input Box တွင် ရိုက်ထည့်လိုက်သည့် စာသား (Text) များကို အရည်အသွေးမြင့်မားပြီး သဘာဝဆန်သော လူသားအသံ (Voice/Speech) အဖြစ်သို့ Real-time ပြောင်းလဲပေးသည့် Web Application တစ်ခု ဖြစ်ပါသည်။

---

## 🚀 Features (ပါဝင်သော လုပ်ဆောင်ချက်များ)
* **Real-time Text-to-Speech:** စာသားများကို ရိုက်ထည့်ပြီး ခလုတ်နှိပ်လိုက်သည်နှင့် ချက်ချင်း အသံထွက်လာခြင်း။


---

## 🛠️ Technologies Used (အသုံးပြုထားသော နည်းပညာများ)
* **Frontend:** HTML5, CSS3 / Tailwind CSS
* **Core API:** JavaScript **Web Speech API** (`SpeechSynthesis`) 

---

## 💻 How to Run (စမ်းသပ်မောင်းနှင်နည်း)

ဒီ Project သည် သီးသန့် Backend Server သို့မဟုတ် External API Keys များ လိုအပ်ခြင်း မရှိပါ။ မိမိစက်ထဲတွင် ဒေါင်းလုဒ်ဆွဲပြီး `index.html` ဖိုင်ကို Browser တွင် (သို့မဟုတ် Open with Live Server ဖြင့်) တိုက်ရိုက်ဖွင့်လှစ်၍ အလွယ်တကူ အသုံးပြုနိုင်ပါသည်။

1. Input Box ထဲတွင် မိမိအသံထွက်စေချင်သည့် အင်္ဂလိပ်စာသားများကို ရိုက်ထည့်ပါ။
2. Dropdown menu မှ မိမိနှစ်သက်ရာ Voice (အသံပုံစံ) ကို ရွေးချယ်ပါ။
3. "Listen" (သို့မဟုတ် Play) ခလုတ်ကို နှိပ်၍ အသံနားထောင်နိုင်ပါသည်။
